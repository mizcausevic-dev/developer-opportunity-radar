Developer Opportunity Radar API

Track public GitHub repositories, cluster recurring issues across them, and trace every finding to its source issue. Base URL for the public read-only demo: https://developer-opportunity-radar.vercel.app. Machine-readable spec: openapi.json.

Conventions

  • Errors use RFC 9457 application/problem+json.
  • Collections use opaque keyset cursors, returned both in the body (page.next_cursor) and as an RFC 8288 Link header.
  • Every 200 response to GET carries a strong ETag; send it back in If-None-Match to get 304 Not Modified.
  • Long-running work (syncs, analyses) returns 202 Accepted with a Location header pointing at a job resource.
  • POST endpoints accept an Idempotency-Key header; a retried request with the same key and body replays the original response.
  • Accept is negotiated with q-values: a request that refuses JSON (e.g. application/json;q=0) gets 406.
  • Every response carries RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset and X-Request-Id.
