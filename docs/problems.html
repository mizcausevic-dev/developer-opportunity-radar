RFC 9457 problem types

Error types

Every error is returned as application/problem+json. The type member is a URI pointing at one of the entries below.

{
  "type": "https://mizcausevic-dev.github.io/developer-opportunity-radar/problems.html#validation-failed",
  "title": "Validation failed",
  "status": 422,
  "detail": "One or more fields are invalid.",
  "instance": "/v1/clusters",
  "errors": [
    {
      "field": "limit",
      "message": "must be an integer between 1 and 100"
    }
  ]
}

400bad-request

Bad request. The request could not be parsed, for example a body that is not a JSON object.

422validation-failed

Validation failed. A path, query or body value is out of range, malformed, repeated or unknown. errors[] lists every offending field.

401unauthorized

Authentication required. A write endpoint was called without Authorization: Bearer <key> or with the wrong key.

403read-only

This deployment is read-only. The deployment has writes disabled (the public demo always does).

404not-found

Resource not found. No route at that path, or the repository, issue, cluster or job does not exist.

405method-not-allowed

Method not allowed. The path exists but not for this method. The Allow header lists what is supported.

406not-acceptable

Not acceptable. The Accept header excludes JSON.

409conflict

Conflict. A request with the same Idempotency-Key is still being processed. Retry after Retry-After seconds.

422idempotency-key-reuse

Idempotency key reused with a different request. The Idempotency-Key was already used with a different method, path or body.

413payload-too-large

Payload too large. The request body exceeds 16 KB.

415unsupported-media-type

Unsupported media type. A body was sent with a Content-Type other than application/json.

400invalid-cursor

Invalid pagination cursor. The cursor is malformed or was issued for different filters or sort. Restart from the first page.

429rate-limited

Too many requests. Too many requests in the current window. Wait Retry-After seconds; RateLimit-* headers show the budget.

502upstream-error

Upstream GitHub API error. GitHub returned an error the API could not recover from after retries.

500internal

Internal server error. An unexpected error. The detail includes the request id to quote when reporting it.
